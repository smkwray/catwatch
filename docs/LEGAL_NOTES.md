# Legal and provenance notes

This repo should maximize openness while minimizing redistribution risk.

## Safe publication posture

- publish code, parsers, schemas, and normalized facts
- preserve source URLs and provenance
- avoid bulk mirroring of copyrighted page text
- avoid republishing proprietary PDFs unless redistribution rights are clear
- distinguish public-domain government data from other public web data

## Source-specific posture

### Government sources
NOAA, NWS, USGS, SEC, and FEMA data are generally suitable as core open inputs, but contributors should still read each source's terms and attribution notes.

### Non-government / exchange / market pages
BSX pages are useful for discovery and fact extraction. Use them to derive structured facts and source references rather than mirroring full text or documents.

## User-facing claims

This project should present itself as:
- a public-data registry,
- a monitoring and research aid,
- an evidence-linked watchlist.

It should not present itself as:
- an official trigger calculator,
- a trading recommendation engine,
- a complete market-data terminal.
